# v1.0.0 — Finite-dictionary predictive adequacy

First licensed software and synthetic-reference release for
*Finite-Dictionary Tests of Predictive Adequacy for State–History Models*.

## Included
Original numerical modules, frozen campaign drivers, synthetic reference outputs,
deterministic tests and terminal-preserving launchers. Includes the main-paper
dependence, inference, fitting/allocation, pair-envelope, finite-binomial and
planning calculations, with six table datasets and four figure datasets.
See `docs/PAPER_REPRODUCTION.md` and `reference/table_figure_map.json` for commands.

## Verification and limitations
The campaign import passed 340 deterministic tests; nine historical replay modes
matched 76 selected numerical JSON files. A further completed WSL fit-pair replay
matched all 22 files. Release preparation rechecks the unchanged 124 imported
identities and the licensing/citation metadata. These are replay and packaging
checks, not new independent statistical evidence or changes to scientific rules.

Checked environment: WSL Python 3.12.3, NumPy 2.3.5, SciPy 1.17.0 and mpmath 1.3.0,
with one numerical-library thread. The historical Python was 3.13.5; observed
agreement is not a universal cross-version guarantee. The guarantees require
independent evaluation groups and a declared predictor dictionary. No physical
cosmological memory detection or autonomous dynamical closure is claimed.
